## Method

Readings were taken between `2026-11-16T06:01:19Z` and `07:25Z` at tree `75b4a214` (clean, level
with `origin/main` at open). Every figure below names the surface that owns it; a figure composed
rather than read is the defect this artifact's own correction pass exists to catch.

**Close counts.** Predicate: rows with `event == 'close'`, `ts` parsed
`datetime.fromisoformat(ts.replace('Z','+00:00'))`, window `now − 7d <= t <= now`, **inclusive at
both ends**, per factory's own `evidence/ledger.jsonl` (member factories' ledgers, not this
repo's). Each factory was recomputed at **both** instants — today's `now` and the prior round's
`now` — and each checksums `prior − aged_out + added = today`. The prior instant was located by
scanning `2026-11-15T06:30Z…09:00Z` for the one that reproduces all published figures (all six
reproduced), rather than assuming the ledger-size stamp's instant, which is a different instant
and produced two near-misses on a previous round.

**Scorecards.** `docs/quality-criteria.md`, scale `0` Absent / `1` Ad-hoc / `2` Defined /
`3` Measured / `4` Self-correcting; bands Provisional 0–25 %, Operational 26–50 %, Scalable
51–75 %, Optimizing 76–100 %; max 76. The rubric is **level-based, not count-based**: a cell moves
only when a stated rung is crossed, so a close count changing does not move a cell by itself. All
six family re-adds were computed and each sums to its card total; the six totals sum to 350.

**Board.** `gh issue list --state all --limit 1000` → 645 total, 574 closed / 71 open.

**Ledger.** `evidence/ledger.jsonl` 5 085 rows, `tools/ledger.py verify` rc=0. Open claims counted
as rows **and** as distinct subjects (7 rows / 5 units), because `verify` counts rows.

**Store.** `~/.opencrabs/profiles/ops/opencrabs.db`, size from `stat`; integrity check backgrounded
and unread at write time (advisory 9). **OOM.** System journal, pattern matching the kernel's own
`oom-kill:` form; positive control over `11-12` returns 1, proving the pattern sees the class.

**Questions.** `~/.opencrabs/profiles/ops/questions/open.json`, `sets` is a list.
**Insights.** `evidence/insights.jsonl` read directly (38 rows) — `insights.py list` takes no
`--json` flag. **Anchor.** `tools/subject_anchor.py`. **Cron.** `cron_job_runs` columns are
`started_at`/`completed_at`; 12 `factory-%` jobs, 11 enabled.

**Arithmetic.** Every figure in this artifact was produced by a script, never by mental
arithmetic — including the family re-adds, the window decompositions and the percentage
divisions. Percentages are quoted to four decimal places because that is what the division
returns, not because the precision is meaningful.
