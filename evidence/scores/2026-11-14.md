## Method

### Instrument

`python3 tools/audit.py --json` ran detached in its own scope
(`audit-tree-2619459-1794636178.scope`, ceiling `2560M`, `MemorySwapMax=0`). The ceiling's basis
is printed by the run itself: a polled peak of `1265.9 MiB` measured `2026-11-07T13:36:37Z`, with
declared headroom of `2×` that peak, rounded up to the next 256 MiB.

| | |
|---|---|
| Launched | `2026-11-14T06:02:58Z` (the scope's own first output) |
| Payload | `/tmp/audit-2026-11-14.json`, **497 196 B**, written `07:44:11Z` |
| Wall | **6 073.24 s** = 101.2207 min |
| Sum of gate durations | `4 443.47 s` → **1 629.77 s** is harness overhead outside the gates |

No peer audit was running during this round's audit — checked, none present at write time — so the
durations are not inflated by a competing suite the way `11-13`'s were. Load at this artifact's
write read `2.61 / 6.85 / 9.29` on four cores.

Every other figure comes from the surface that owns it: systemd for units, the filesystem for
sizes, `tools/ledger.py` for ledger state, `tools/subject_anchor.py` for the documentation gate,
`tools/brain_metrics.py` for the context budget, `tools/insights.py` for the insights ledger, and
each factory's own `evidence/ledger.jsonl` for per-day counts.

### Exclusivity

One writer per surface, per the state table in the factory's law. This artifact is the only writer
of `evidence/scores/2026-11-14.md`. Nothing here edits a member factory's state, and no figure
here is a copy of a member's own published number — where a member publishes its own score, that
number is theirs and this artifact's is this round's reading.

  prior draft had aged out two days when the window advanced one. A total alone could not have
